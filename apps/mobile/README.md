# تطبيق مزاد للجوال (Expo / React Native)

هيكل أولي يعرض الإعلانات من نفس الواجهة الخلفية. يتطوّر لاحقاً ليشمل المصادقة، إنشاء الإعلان، والمزاد المباشر (مشاركة المنطق مع الويب عبر `packages/`).

## التشغيل
```bash
pnpm --filter @mazad/mobile start
```
ثم افتح التطبيق عبر Expo Go على جوالك، أو محاكي iOS/Android.

> ملاحظة: على المحاكي/الجهاز الحقيقي، غيّر `apiUrl` في `app.json` إلى عنوان IP لجهازك بدل `localhost`.
