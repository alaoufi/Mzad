# مواصفات: الإعلانات المبوبة والمساحات الإعلانية

> متطلبات من المالك ليُحسب حسابها. الإدارة الكاملة تحتاج جدولاً جديداً (ضمن "التعديل الكبير").

---

## 1. المساحات الإعلانية (Ad Placements) — مصدر دخل
مساحات مخصّصة لعرض إعلانات (بانرات) في مواضع محدّدة، **تديرها الإدارة**.

### المواضع المقترحة (Placement)
| الموضع | المكان |
|--------|--------|
| `HOME_TOP` | أعلى الصفحة الرئيسية (تحت الهيرو) |
| `HOME_MID` | بين الإعلانات في الرئيسية |
| `MARKET_TOP` | أعلى سوق معيّن (إبل/خيل/مستلزمات…) |
| `LISTING_DETAIL` | داخل صفحة الإعلان |
| `SEARCH_RESULTS` | ضمن نتائج البحث |
| `SUPPLIES_TOP` | أعلى سوق المستلزمات |

### الاستهداف (Targeting)
- **حسب السوق/النوع:** إعلان يظهر فقط في سوق الإبل مثلاً.
- **حسب المنطقة:** يظهر لمستخدمي منطقة معيّنة.
- **حسب المدة:** تاريخ بداية/نهاية (حملة مجدولة).
- **الأولوية:** ترتيب الظهور عند تزاحم الإعلانات.

### الإدارة (لوحة الإدارة)
- إنشاء/تعديل/حذف إعلان: العنوان، الصورة، الرابط (داخلي لإعلان/خارجي)، الموضع، المدة، الحالة (نشط/موقوف).
- جدولة الحملات وتفعيلها/إيقافها.
- إحصائيات: مرّات الظهور (Impressions) والنقرات (Clicks) ونسبة النقر (CTR).
- التسعير: حسب الموضع والمدة (يومي/أسبوعي)، ومساحات "مميّزة".

## 2. الإعلانات المبوبة (Classified Ads)
لوحة إعلانات صغيرة يضيفها المستخدمون ضمن **أقسام وأماكن محدّدة**، منفصلة عن إعلانات المواشي:
- أقسام (وظائف/خدمات نقل/عقار مزارع/أدوات…) — تُدار من الإدارة.
- موقع جغرافي لكل إعلان (المنطقة/المدينة) لتحديد مكان ظهوره.
- مراجعة وموافقة الإدارة قبل النشر (نفس آلية الموافقات الحالية).
- تمييز مدفوع (تثبيت أعلى القسم / إبراز).

## 3. إعلانات الموقع الخاصة (House Ads) — الاسم لاحقاً
إعلانات المنصّة نفسها (ترويج داخلي/إعلانات/تنبيهات):
- بدون مُعلِن خارجي؛ تُعرض في نفس المواضع.
- أمثلة: "سوق المستلزمات الجديد"، "وثّق حسابك"، إعلانات موسمية (الأضاحي).
- نوع الإعلان: `HOUSE`.

## نموذج البيانات المقترح (للتعديل الكبير)
```prisma
enum AdType { BANNER CLASSIFIED HOUSE }
enum AdPlacement { HOME_TOP HOME_MID MARKET_TOP LISTING_DETAIL SEARCH_RESULTS SUPPLIES_TOP }
enum AdStatus { DRAFT ACTIVE PAUSED EXPIRED }

model Ad {
  id           String   @id @default(uuid())
  type         AdType
  title        String
  imageUrl     String?
  link         String?       // رابط داخلي أو خارجي
  placement    AdPlacement
  status       AdStatus  @default(DRAFT)
  priority     Int       @default(0)
  targetSpeciesId String?    // استهداف سوق معيّن (Category)
  targetRegion String?
  startAt      DateTime?
  endAt        DateTime?
  advertiser   String?       // اسم المُعلِن (فارغ لإعلانات الموقع)
  impressions  Int       @default(0)
  clicks       Int       @default(0)
  createdAt    DateTime  @default(now())
}
```

## واجهات العرض
- مكوّن `<AdSlot placement="HOME_TOP" market={speciesId} region={...} />` يجلب الإعلان المناسب ويعرضه (مع تسجيل ظهور/نقرة).
- منفّذ حالياً كـ **نموذج مرئي ثابت** على الرئيسية (`components/AdBanner.tsx`) لتوضيح المكان، ويُربط لاحقاً بقاعدة البيانات.

## الحالة
- 🔜 جدول `Ad` + الإدارة + الاستهداف + الإحصائيات (ضمن التعديل الكبير).
- ✅ نموذج مرئي لموضع `HOME_TOP` لإظهار الفكرة.
