# خطة التطوير (Roadmap)

> خطة مرحلية واقعية تبدأ بنموذج أولي مقلّص وتتوسّع تدريجياً. المبدأ: **أطلِق مبكراً، تعلّم، ثم وسّع**.

---

## نظرة عامة على المراحل

| المرحلة | المدة التقديرية | الهدف | المخرج |
|---------|------------------|-------|--------|
| **0 — التأسيس** | أسبوعان | البنية والهيكل | Monorepo، CI/CD، قاعدة بيانات، مصادقة |
| **1 — MVP (الحالي)** | 6–8 أسابيع | إثبات القيمة | إعلانات + مزاد لحظي + توثيق + محادثة |
| **2 — الثقة والدفع** | 6–8 أسابيع | تمكين المعاملات | الدفع، المحفظة، التقييم، مكافحة الاحتيال |
| **3 — البث المباشر** | 6–10 أسابيع | تجربة الحراج الحي | بث WebRTC، دلال رقمي، مزاد جماعي |
| **4 — الذكاء الاصطناعي** | 8–12 أسبوع | تقليل الإدخال | إنشاء/بحث صوتي، فهم اللهجة، تحقّق الصور |
| **5 — التوسّع** | مستمر | النمو | الأمانة، التأمين، NFC، التوسّع الإقليمي |

---

## المرحلة 0 — التأسيس (Foundation)
**الهدف:** أرضية تقنية صلبة.
- [x] إعداد Monorepo (pnpm workspaces).
- [x] هيكل الواجهة الخلفية (NestJS) والويب (Next.js) والجوال (Expo).
- [x] قاعدة بيانات PostgreSQL + Prisma + الترحيلات.
- [x] مصادقة بالجوال (OTP).
- [ ] خط CI/CD (GitHub Actions) + بيئات (dev/staging/prod).
- [ ] رصد الأخطاء (Sentry) + تحليلات (PostHog).

## المرحلة 1 — MVP ✅ (منفّذ في هذا المستودع)
**الهدف:** أصغر منتج يثبت أن الناس يبيعون ويشترون عبر المنصة.
- [x] تصنيف هرمي للمواشي + بيانات تجريبية.
- [x] إنشاء إعلان بمعالج (Wizard) + الحالة الصحية والعيوب + الميديا.
- [x] تصفّح/بحث/فلترة + ترتيب جغرافي.
- [x] مزاد بسيط بمزايدة لحظية (Socket.IO) + Anti-sniping + حماية التزامن.
- [ ] محادثة بين البائع والمشتري (هيكل جاهز).
- [ ] توثيق الجوال + شارات ثقة أساسية.
- **معيار النجاح:** ≥ 50 إعلاناً حقيقياً و ≥ 10 صفقات في منطقة الإطلاق.

## المرحلة 2 — الثقة والدفع (Trust & Payments)
- بوابة دفع (Moyasar/HyperPay/Tap) — العربون والعمولة فقط (لا بيع السلعة داخل التطبيق على iOS).
- المحفظة والسجل المالي + الفوترة الإلكترونية (ZATCA).
- التقييم المتبادل + سجل الثقة + نسبة مطابقة الوصف.
- مكافحة الاحتيال: كشف الصور المكرّرة، حدود المزايدة، مراجعة البلاغات.
- مركز النزاعات بمسار واضح (SLA + أدلة + قرار + استرداد).

## المرحلة 3 — البث المباشر والدلال (Live & Broker)
- البث المباشر (WebRTC + Agora/AWS IVS) مع دردشة وإدارة مشاركين وتسجيل.
- أدوات إبلاغ/حجب فورية داخل البث (شرط المتاجر).
- صلاحيات الدلال الكاملة + خدمة "الدلال الرقمي" + "المندوب الرقمي".
- المزاد الجماعي المجدول (سوق أسبوعي).

## المرحلة 4 — الذكاء الاصطناعي والصوت (AI & Voice)
- إنشاء الإعلان بالصوت (Whisper + استخراج حقول).
- البحث الصوتي وفهم اللهجات البدوية/المحلية.
- المساعد التفاعلي (Wizard ذكي).
- تقدير الوزن/العمر والتحقق من الصور بالرؤية الحاسوبية.

## المرحلة 5 — التوسّع (Scale)
- نظام الأمانة (Escrow) الكامل + ضمان المنصة.
- التأمين أثناء النقل + شركاء لوجستيات.
- ربط NFC/RFID والترقيم الوطني.
- سوق الخدمات البيطرية والأعلاف.
- التوسّع الإقليمي (لهجات وعملات متعددة).

## مؤشرات الأداء الرئيسية (KPIs)

- **النمو:** عدد الإعلانات النشطة، المستخدمون النشطون أسبوعياً (WAU).
- **التفعيل:** نسبة إكمال أول إعلان، نسبة من زايد مرة واحدة على الأقل.
- **المعاملات:** عدد الصفقات المتمّة، GMV (حجم التداول)، متوسط قيمة الصفقة.
- **الثقة:** نسبة البلاغات لكل 1000 إعلان، نسبة النزاعات المحلولة، متوسط التقييم.
- **الاحتفاظ:** معدّل العودة بعد 30 يوماً.
