# البنية التقنية (Architecture)

> معمارية قابلة للتوسّع تبدأ بسيطة (Modular Monolith) وتتطوّر إلى Microservices عند الحاجة.

---

## 1. القرار المعماري: Modular Monolith أولاً

الوثيقة الأصلية طلبت Microservices. التوصية للنموذج الأولي ومرحلة الإطلاق هي **Modular Monolith** (NestJS مقسّم لوحدات معزولة) للأسباب التالية:
- أسرع للتطوير والنشر وأقل تكلفة تشغيلية في البداية.
- حدود الوحدات (Modules) واضحة، فالانتقال لـ Microservices لاحقاً سهل (كل وحدة → خدمة).
- نفصل أولاً ما يحتاج فعلاً للعزل: **البث المباشر** و **معالجة الميديا** (خدمات مستقلة).

> القاعدة: لا تبدأ بـ Microservices قبل أن يفرضها الحِمل أو الفريق.

## 3. الحزمة التقنية (Tech Stack)

| الطبقة | التقنية | السبب |
|--------|---------|-------|
| الويب / لوحة التحكم | **Next.js 14 (App Router)** | SSR للـ SEO، RTL، أداء |
| الجوال | **React Native (Expo)** | كود مشترك iOS/Android |
| الواجهة الخلفية | **NestJS (Node.js)** | معماري، قابل للاختبار، WebSockets مدمج |
| ORM | **Prisma** | أمان أنواع، ترحيلات سهلة |
| قاعدة البيانات | **PostgreSQL** | علائقية + PostGIS للموقع |
| الكاش/اللحظي | **Redis** | كاش، أقفال موزّعة، Pub/Sub للمزاد |
| اللحظي | **Socket.IO** | مزايدة وبث الأحداث |
| التخزين | **S3 / Cloudflare R2** | ميديا |
| البحث | **PostgreSQL FTS → Elasticsearch** | يبدأ بسيطاً، يتوسّع |
| الإشعارات | **FCM + APNs** | Push |
| البث | **Agora / AWS IVS** | منخفض زمن الاستجابة |
| الـ AI | **OpenAI Whisper + NLP** | صوت ولهجة |
| البنية | **Docker → Kubernetes** | يبدأ Compose، يتوسّع K8s |

## 4. تدفّق المزايدة اللحظية (نقطة حرجة)

```
المزايد ──bid──▶ Socket.IO Gateway
                     │
                     ▼
            قفل Redis على المزاد (SETNX)
                     │
                     ▼
   معاملة قاعدة بيانات (SERIALIZABLE):
     - تحقق أن العرض > أعلى عرض + الحد الأدنى للزيادة
     - تحقق أن المزاد مفتوح والوقت لم ينتهِ
     - أنشئ سجل المزايدة، حدّث أعلى عرض
     - Anti-sniping: إن بقي < 60s، مدّد النهاية 60s
                     │
                     ▼
            فكّ قفل Redis + بثّ الحدث (broadcast)
                     │
                     ▼
   كل المشاهدين يستلمون أعلى عرض + الوقت الجديد فوراً
```

هذا يمنع **Race Conditions** (مزايدتان في نفس الميلي ثانية) ويضمن العدالة. منفّذ في `apps/api/src/auctions`.

## 5. الأمن والامتثال

- **المصادقة:** JWT قصير العمر + Refresh، OTP بالجوال، اختياري ترقية للتوثيق بالهوية.
- **الصلاحيات:** RBAC (مستخدم، دلال، إدارة) عبر Guards في NestJS.
- **حماية البيانات:** تشفير بيانات الهوية، إخفاء الأرقام (Number Masking)، حذف الحساب والبيانات (سياسة المتاجر).
- **حدود المعدّل (Rate Limiting):** على OTP، المزايدة، ورفع الميديا.
- **Trust & Safety:** إبلاغ/حجب، طابور مراجعة، سجل تدقيق (Audit Log).

---

## 6. قابلية التوسّع (Scaling Path)

1. **عمودي** أولاً (خادم أكبر) — كافٍ لعشرات الآلاف.
2. **أفقي:** عدة نسخ من الـ API خلف موازِن حِمل + Redis Adapter لـ Socket.IO.
3. **فصل الخدمات الثقيلة:** البث، معالجة الميديا، البحث.
4. **قاعدة البيانات:** نسخ قراءة (Read Replicas) + تقسيم (Partitioning) لجداول المزايدات.
