# منصة "مزاد" — سوق ومزادات المواشي الرقمي 🐪

> نقل تجربة "الحراج والدلالة" الواقعية إلى البيئة الرقمية بمصداقية مطلقة.

منصة عربية متخصصة في بيع وشراء ومزادات المواشي (إبل، غنم، ماعز، بقر، خيل)، مبنية ليستخدمها كبار السن ومحدودو الخبرة التقنية بسهولة (مبدأ "اختبار الجد").

## 🚀 التشغيل السريع (Quick Start)

المتطلبات: Node.js ≥ 20، pnpm ≥ 9، Docker (لقاعدة البيانات).

```bash
# 1) تثبيت الحزم
pnpm install

# 2) تشغيل قاعدة البيانات (PostgreSQL + Redis)
docker compose up -d

# 3) تجهيز قاعدة البيانات وبياناتها التجريبية
pnpm --filter @mazad/api prisma:migrate
pnpm --filter @mazad/api prisma:seed

# 4) تشغيل الواجهة الخلفية والويب معاً
pnpm dev
```

- الواجهة الخلفية (API): http://localhost:4000
- تطبيق الويب: http://localhost:3000
- توثيق الـ API (Swagger): http://localhost:4000/docs

> راجع [دليل التشغيل التفصيلي](./docs/07-getting-started.md).

## ✅ ما المنفّذ في هذا النموذج الأولي (MVP)

- [x] مصادقة بالجوال عبر رمز OTP (وضع تطوير يطبع الرمز في السجل).
- [x] تصنيف هرمي للمواشي (نوع ← فئة ← سلالة) مع بيانات تجريبية.
- [x] إنشاء إعلان بمعالج خطوة-بخطوة (Wizard) مع الحالة الصحية والعيوب.
- [x] تصفّح وبحث وفلترة الإعلانات مع الترتيب الجغرافي.
- [x] مزاد مباشر بمزايدة لحظية (Realtime) عبر Socket.IO مع حماية ضد الـ Race Conditions وميزة Anti-sniping.
- [x] واجهة عربية RTL بأزرار ضخمة متوافقة مع "اختبار الجد".
- [ ] (المراحل القادمة) البث المباشر، الذكاء الاصطناعي الصوتي، الدفع، نظام الأمانة — مفصّلة في [خطة التطوير](./docs/04-roadmap.md).
