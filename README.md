# منصة "مزاد" — سوق ومزادات المواشي الرقمي 🐪

> نقل تجربة "الحراج والدلالة" الواقعية إلى البيئة الرقمية بمصداقية مطلقة.

منصة عربية متخصصة في بيع وشراء ومزادات المواشي (إبل، غنم، ماعز، بقر، خيل)، مبنية ليستخدمها كبار السن ومحدودو الخبرة التقنية بسهولة (مبدأ "اختبار الجد").

## 🚀 أسهل طريقة للتجربة — أمر واحد فقط

المتطلبات: **[Docker Desktop](https://www.docker.com/products/docker-desktop/)** فقط. ثم:

```bash
docker compose up
```

انتظر حتى يكتمل البناء، ثم افتح **http://localhost:3000** 🎉
(يُنشئ قاعدة البيانات ويعبّئها بالبيانات التجريبية تلقائياً. سجّل دخول بجوال `0500000001` والرمز يظهر على الشاشة.)

> **تريد رابطاً على الإنترنت تشاركه؟** اتبع [دليل النشر المبسّط](./docs/08-deploy.md).

## 🛠️ التشغيل للتطوير (Dev Mode)

المتطلبات: Node.js ≥ 20، pnpm ≥ 9، Docker.

```bash
pnpm install
docker compose up -d postgres                      # قاعدة البيانات فقط
pnpm --filter @mazad/api prisma:migrate
pnpm --filter @mazad/api prisma:seed
pnpm dev                                            # API على 4000 + الويب على 3000
```

- تطبيق الويب: http://localhost:3000
- الواجهة الخلفية (API): http://localhost:4000 · توثيق Swagger: http://localhost:4000/docs

> راجع [دليل التشغيل التفصيلي](./docs/07-getting-started.md).

### 🌐 نشر رابط مباشر على الإنترنت
تطبيق الويب **مكتفٍ ذاتياً وقابل للنشر** على Vercel + Neon بدون خادم منفصل (يستخدم مسارات API داخلية + قاعدة Neon + مزايدة بالاستطلاع الدوري). اتبع [**دليل النشر — رابط خلال دقيقتين**](./docs/08-deploy.md). ملف تهيئة قاعدة البيانات الجاهز: [`deploy/neon-init.sql`](./deploy/neon-init.sql).

## ✅ ما المنفّذ في هذا النموذج الأولي (MVP)

- [x] مصادقة بالجوال عبر رمز OTP (وضع تطوير يطبع الرمز في السجل).
- [x] تصنيف هرمي للمواشي (نوع ← فئة ← سلالة) مع بيانات تجريبية.
- [x] إنشاء إعلان بمعالج خطوة-بخطوة (Wizard) مع الحالة الصحية والعيوب.
- [x] تصفّح وبحث وفلترة الإعلانات مع الترتيب الجغرافي.
- [x] مزاد مباشر بمزايدة لحظية (Realtime) عبر Socket.IO مع حماية ضد الـ Race Conditions وميزة Anti-sniping.
- [x] واجهة عربية RTL بأزرار ضخمة متوافقة مع "اختبار الجد" + تصميم عصري وتنقّل سفلي للجوال.
- [x] رفع صور حقيقية من الجوال (ضغط تلقائي في المتصفح).
- [x] صفحة "حسابي": الملف الشخصي، إحصائيات الثقة، وإعلاناتي.
- [x] محادثات داخل الإعلان (أسئلة واستفسارات) + صندوق رسائلي.
- [x] نظام التقييمات والمراجعات المتبادلة (مع نسبة مطابقة الوصف).
- [x] لوحة تحكم للإدارة (إحصائيات، إدارة الإعلانات، البلاغات).
- [ ] (المراحل القادمة) البث المباشر، الذكاء الاصطناعي الصوتي، الدفع، نظام الأمانة — مفصّلة في [خطة التطوير](./docs/04-roadmap.md).
